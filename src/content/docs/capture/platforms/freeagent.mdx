Otto Capture connects to FreeAgent so you can publish bills and sales invoices straight into your client's FreeAgent company. For the connection basics, see [Connecting your accounting platform](/capture/platforms/connecting-your-accounting-platform).

## Connecting a client

There are two ways to connect FreeAgent: a **Company** connection for a single business you run, or a **Practice** connection for adding clients from your FreeAgent practice.

### Company

A Company connection maps one FreeAgent company to one client in Capture. The person who authorises the connection needs permission to manage Bills in that company.

<Steps>
    1. From the **Clients** page in Capture, click **Add client**, then choose the FreeAgent option described as **I run my own business**

    2. Sign in to FreeAgent and authorise Capture for the company

    3. You'll be redirected back to Capture, and Capture connects the company as a single client

</Steps>

### Practice

If you're a FreeAgent practice, you connect once and then add any of your managed clients. You don't authorise each client separately.

<Steps>
    1. From the **Clients** page in Capture, click **Add client**, then choose the FreeAgent option described as **Add a FreeAgent client from your practice**

    2. Capture shows the **Add FreeAgent clients** page, listing your practice's FreeAgent clients with their entity type

    3. Tick the clients you want and click **Add selected clients**. Capture creates a client for each, with its own inbox and setup

</Steps>

Every client you add this way shares the one practice connection, so there's a single sign-in to keep healthy. Adding more later needs no new authorisation, just another visit to the **Add FreeAgent clients** page, where clients you've already added show **Connected** and only the rest can be selected.

## Permissions

The authorising user needs permission to manage Bills in FreeAgent. Capture uses this access only to read the reference data it needs and to publish bills and invoices, nothing else. If Capture's access isn't high enough, the client moves to **Connection failed**, and someone with the right permission needs to reconnect it before Capture can sync or Otto can publish.

## Synced data

Once connected, Capture syncs the following from FreeAgent:

| Data                     | Purpose                                                               |
| ------------------------ | --------------------------------------------------------------------- |
| **Contacts**             | Match suppliers and customers to extracted document data              |
| **Categories**           | Assign nominal codes to line items                                    |
| **Tax rates**            | Apply the correct tax treatment to line items                         |
| **Currencies**           | Set the document currency                                             |
| **Organisation details** | Base currency and other details needed to process documents correctly |

## Publishing

When Otto publishes to FreeAgent:

- **Bills** go straight into the ledger.
- **Sales invoices** start as **Draft**.

### Credit notes

Otto publishes a sales credit note as a FreeAgent credit note, mirroring how he publishes sales invoices, so it carries no attached file. He records a purchase credit note on the bill side as a supplier credit, because FreeAgent has no separate purchase credit note record, and attaches the original document as he does for a bill.

## VAT

FreeAgent records a VAT reporting status on each document. Otto supports two:

| Status             | When to use                                      |
| ------------------ | ------------------------------------------------ |
| **UK VAT rates**   | The default, for standard UK VAT treatment       |
| **Reverse charge** | When the document falls under the reverse charge |

Whether a company accepts a non-default status depends on its own FreeAgent VAT settings, which FreeAgent checks when Otto publishes.

## Currencies

FreeAgent supports a fixed set of currencies and applies its own exchange rate, so a document in any supported currency, base or not, publishes without extra confirmation. The supported list can't be extended, so if a document is in a currency FreeAgent doesn't support, restate the amounts using the converter on the review screen before publishing. See [Currency and conversion](/capture/guides/reviewing#currency-and-conversion).

## Attachments

Otto attaches the original document to **bills** in FreeAgent, up to 5 MB, in PDF, PNG, JPEG, or GIF format. He publishes sales invoices without an attached file. Either way, the original document stays in Capture.

## Disconnecting and reconnecting

Disconnecting a client in Capture stops syncing and publishing on Capture's side, and deletes the data synced from FreeAgent along with the supplier matches Otto has learned for the client (see [Disconnecting and reconnecting](/capture/platforms/connecting-your-accounting-platform#disconnecting-and-reconnecting)). FreeAgent gives Capture no way to revoke its own access, so to remove it completely, do that inside FreeAgent's own settings.

Capture checks each FreeAgent connection once a day, so if access is removed inside FreeAgent the client moves to **Disconnected**. Reconnecting from the client settings syncs the data again and resumes publishing.
