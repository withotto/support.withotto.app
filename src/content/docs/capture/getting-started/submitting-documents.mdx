There are four ways to submit documents to Capture: uploading through the web interface, forwarding them by email, sending them over WhatsApp, or using a client submission page. Documents also arrive when a Xero or FreeAgent client answers your questions about their bank payments on their client missing receipts page.

Whichever route a document takes, Otto usually has it ready in the client's review queue within a minute.

## Upload via the web

From your client's document inbox, drag files onto the page, or click the upload button and choose them.

## Email submission

Forward receipts and invoices to the client's email address (set up in [client configuration](/capture/getting-started/configuring-clients/)). Each attachment becomes a separate document, and an email with no attachments is read as a document itself. Otto also reads the email body, so a note about what a purchase was for helps him code it. The same email sent twice is only processed once.

<Aside type="tip">
  Email submission is particularly useful when your clients can forward receipts
  directly from their inbox. Set up an email forwarding rule to automate this
  completely.
</Aside>

## WhatsApp submission

The people who hold a client's receipts can send them over WhatsApp, with no app to download and nothing to sign in to. They connect by tapping an invite link you share. See [WhatsApp submission](/capture/getting-started/whatsapp-submission/).

## Client submission page

Each client has its own submission page: a link you share with whoever sends their receipts and invoices, who can then take a photo or choose files to send. See [Client submission page](/capture/getting-started/client-submission-page/).

## Client missing receipts page

For Xero and FreeAgent clients, you can ask about the bank payments you have no paperwork for. The client answers each one on their own page, and a receipt they send arrives in the review queue with their note attached. See [Missing receipts](/capture/missing-receipts/).

## Document statuses

Every document is scanned for malware, then Otto works out what kind of document it is, extracts its data, and matches its contact. [How Capture processes documents](/capture/guides/processing/) covers each stage.

| Status                   | Meaning                                                                                                                    |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| **Pending upload**       | The file is still uploading                                                                                                |
| **Pending scan**         | Waiting for malware scan to complete                                                                                       |
| **Scan failed**          | The malware scan didn't finish, or Capture couldn't prepare the file for processing. Discard it and upload it again        |
| **Queued**               | In the processing queue                                                                                                    |
| **Processing**           | Otto is working on it                                                                                                      |
| **Triage failed**        | Otto couldn't confirm it's a genuine financial document                                                                    |
| **Extraction failed**    | Otto couldn't extract data from the document                                                                               |
| **Needs review**         | Extraction complete, ready for you to check                                                                                |
| **Needs classification** | Otto couldn't determine the document type                                                                                  |
| **Needs manual split**   | Several documents in one image. Send them separately, or click **Process as one document** if they belong together         |
| **Reviewed**             | You've reviewed and confirmed the data                                                                                     |
| **Publishing**           | Being sent to your accounting platform                                                                                     |
| **Published**            | Successfully published to your accounting platform                                                                         |
| **Publish failed**       | Failed to publish. Check the error and retry                                                                               |
| **Quarantined**          | Malware detected, file has been quarantined                                                                                |
| **Discarded**            | Discarded by a user. The [reason they chose](/capture/guides/reviewing/#discarding-documents) shows under the contact name |
| **Duplicate detected**   | The same file has already been sent in for this client. Click **Process anyway** if it should be captured again            |
